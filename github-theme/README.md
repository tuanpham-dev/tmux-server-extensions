# GitHub Theme

GitHub's own color themes for VS Code, packaged for tmux-server.

## Contributes

- **Color themes:** GitHub Light Default, GitHub Light High Contrast, GitHub Light Colorblind (Beta), GitHub Dark Default, GitHub Dark High Contrast, GitHub Dark Colorblind (Beta), GitHub Dark Dimmed, and the classic GitHub Light / GitHub Dark. Each covers the editor, terminal ANSI palette, sidebar, tabs, git-status colors, and syntax highlighting (`tokenColors`).

## Source

[primer/github-vscode-theme](https://github.com/primer/github-vscode-theme) 6.3.5 (`GitHub.github-vscode-theme` on the VS Code Marketplace), MIT-licensed - see `LICENSE.txt`. The theme JSON files are copied unmodified from the published VSIX.

## Notes

Install from the Extensions tab, then pick one from Settings → UI → Color theme.
