# One Dark Pro

The full **One Dark Pro** theme family — One Dark Pro, Flat, Darker, Mix, and Night Flat — bundled as-is from the upstream extension package.

## Contributes

- **Color themes:** One Dark Pro, One Dark Pro Flat, One Dark Pro Darker, One Dark Pro Mix, One Dark Pro Night Flat

## Source

[Binaryify/OneDark-Pro](https://github.com/Binaryify/OneDark-Pro), MIT-licensed; see `LICENSE.txt`. Theme JSONs and icon vendored unmodified from the published extension package.

## Install

```sh
npm run pack
```

Then, in tmux-server's Extensions sidebar tab:
- **Registry (recommended):** click the gear icon, add this repo's `dist/` folder as a source, and click Install on One Dark Pro.
- **Manual:** click "Install from .tsix" and pick `dist/one-dark-pro-theme-<version>.tsix`.
